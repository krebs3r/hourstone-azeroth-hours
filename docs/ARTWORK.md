# Artwork provenance

`assets/Logo.png` is the AI-generated Hourstone logo: a grey teleport stone, blue rune and golden hourglass. The original [Soundstone icon sheet](https://github.com/krebs3r/soundstone-azeroth-audio/blob/main/docs/icons-source.png) served as its visual reference. The 1254 × 1254 RGBA master is retained. `tools/assets.py` resizes it to 256 × 256 and writes uncompressed 32-bit TGA data with alpha for WoW.

`RetailPanel.png`, `ClassicPanel.png` and `HeaderClose.png` originate in [Soundstone's assets](https://github.com/krebs3r/soundstone-azeroth-audio/tree/main/docs/assets). They are converted to TGA without resizing. Copyright © 2026 krebs3r, MIT; the repository and installable addon include the license. The addon renders frames as nine texture regions to preserve corners.

Soundstone `Toggle`, `ToggleRed`, `Rivet`, `GoldThumb` and `SilverThumb` assets are pinned to commit `85290d29c3de18f8612d679b093e509e6725d890`. [The source manifest](assets/soundstone-manifest.json) retains source PNG bytes and Git blob hashes. Tests compare every RGBA pixel with the shipped TGA files.

Control backgrounds, arrows, grip dots, check marks, gear, heart and the legacy minimap shapes are generated by `tools/assets.py`. The heart uses #A75466. The generated minimap background, border and hover files remain bundled for package compatibility, but are no longer displayed at runtime.

The runtime uses WoW's own standard font, gear texture and checkbox template where applicable. The 31-unit minimap button references Blizzard's `MiniMap-TrackingBorder` (136430), `UI-Minimap-Background` (136467) and `UI-Minimap-ZoomButton-Highlight` (136477), with the client-specific geometry used by [LibDBIcon](https://www.wowace.com/projects/libdbicon-1-0). No library source is included. The complete Hourstone logo is centered within the circular mask; Retail and Classic retain the native placement appropriate to their textures.

These client-owned Blizzard resources are referenced directly from WoW and are not redistributed or covered by the MIT code license. Browser previews approximate their appearance and use synthetic character data; native font and minimap rendering require in-game review. See [font provenance](FONTS.md).
