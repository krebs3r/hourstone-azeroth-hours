# Hourstone – Azeroth Hours

This directory is the canonical project and Git checkout.

- `Hourstone/`: installable addon source.
- `docs/`: documentation, artwork masters, Mockup 04 and Mockup 05.
- `docs/curseforge/`: listing, logo, native screenshot and publication status.
- `tests/`, `tools/`, `.github/`: verification and release tooling.
- `dist/`: current installable release ZIP and checksum (generated, not committed).
- `.local-history/deliverables/`: all earlier test ZIPs and standalone mockups.
- `.local-history/work/`: preserved development scripts, references and local dependencies.

The previous task's repository, mockup and work paths are compatibility junctions into this directory. Project data is physically stored here. Local history is excluded from Git.
