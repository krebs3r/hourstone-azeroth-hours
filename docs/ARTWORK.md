# Artwork provenance

`assets/Logo.png` is the AI-generated Hourstone logo: a grey teleport stone, blue rune and golden hourglass. The original [Soundstone icon sheet](https://github.com/krebs3r/soundstone-azeroth-audio/blob/main/docs/icons-source.png) served as its visual reference. The 1254 × 1254 RGBA master is retained. `tools/assets.py` resizes it to 256 × 256 and writes uncompressed 32-bit TGA data with alpha for WoW.

`RetailPanel.png`, `ClassicPanel.png` and `HeaderClose.png` originate in [Soundstone's assets](https://github.com/krebs3r/soundstone-azeroth-audio/tree/main/docs/assets). They are converted to TGA without resizing. Copyright © 2026 krebs3r, MIT; the repository and installable addon include the license. The addon renders frames as nine texture regions to preserve corners.

Soundstone `Toggle`, `ToggleRed`, `Rivet`, `GoldThumb` and `SilverThumb` assets are pinned to commit `85290d29c3de18f8612d679b093e509e6725d890`. [The source manifest](assets/soundstone-manifest.json) retains source PNG bytes and Git blob hashes. Tests compare every RGBA pixel with the shipped TGA files.

Control backgrounds, arrows, grip dots, check marks, gear, heart and minimap shapes are generated by `tools/assets.py`. The minimap displays the complete logo inside its circular border. Some generated assets remain bundled for package compatibility and development previews.

The runtime uses WoW's own standard font, gear texture and checkbox template where applicable. Those client-owned resources are not redistributed. Browser previews approximate them and use synthetic character data. See [font provenance](FONTS.md).
